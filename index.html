How it works

Three steps, all inside the editor.

No external editors, no JSON wrangling, no copy-pasting object strings. The mod lives inside the game and writes directly into the level you already have open.

STEP 01

Press Generate

The button sits in the editor toolbar next to Build Helper. Click it and the Generate panel opens — it knows your song, your BPM and your current cursor position.

STEP 02

Prompt it, or pick a song

Type what you want ("slow easy cube part with portals"), or choose any track from your in-game saved song library — official GD music or your own imported files. Sync is derived from the chosen song.

STEP 03

Generate & playtest

Objects are placed from your cursor forward as a real level. Undo works normally — the whole generation lands as one undo stack entry so you can nuke it in a single Ctrl+Z.

Features

Everything the generator understands.

Every option is a real toggle in the panel — not a prompt keyword you have to guess. Mix them however you like.

Version-aware object sets

Every version from 1.0 to 2.2 is selectable, none skipped. Pick one and the generator only uses objects, triggers and mechanics that existed in that update — no anachronistic teleport portals in a 1.9 level.

Orbs, pads & portals

Toggle each gadget class independently. The generator places them at jump arcs that are actually reachable — verified against the real hitboxes, not guessed.

Layout or full decorated

Layout mode gives you clean, readable structure to build over. Decorated mode adds block design, ground styling, pulses, move triggers and camera work.

Song-driven sync

Pick a track from your saved library and the level snaps to its beat grid. Structure follows the actual song — intro, build, drop, outro — not a fixed length.

Difficulty targeting

Ask for Easy, Normal, Hard, Harder, Insane or Extreme. Gap sizes, timing windows and gadget density all scale with the tier you select.

Regenerate & iterate

Not feeling it? Re-roll the same settings for a different seed, or keep the layout and ask for decoration only. One undo per pass.

Playability guard

Every generated segment is checked for impossible gaps, ceiling traps and unreachable coins before it's committed. Broken patterns are re-rolled automatically.

Objects only, no bloat

Output is ordinary editor objects — no custom IDs, no mod dependency baked into the level. Share it with vanilla players and it still opens fine.

Tracks Geode releases

Built on Geode's public API with no hardcoded game addresses. When a new GD build lands, GENESIS follows it with a matching build — 2.2091 support ships on the Geode 6 line.

Install

Drop it in. Open the editor. Press Generate.

Generate ships as a standard .geode package. If you already run Geode, install it straight from the in-game mod browser — search GENESIS — or grab the file on the download page.

01Install Geode for your platform and launch GD once so the loader sets up.
02Open Mods → Browse and install GENESIS, or drop the .geode file into your mods folder.
03Restart, open the Level Editor, and hit the new Generate button.

FAQ

Questions, answered.

Does the generated level count as my own?

The mod outputs ordinary editor objects into your own level file. How you publish it is up to you — but most creators use it for layout drafts, decoration bases and quick playtestable structures rather than publishing raw output unchanged.

Which songs can it sync to?

Any track available in your in-game saved music library — the official GD soundtrack, songs you've downloaded through the game, and your own imported audio files. Sync tempo and offset are read from the track and used as the generation beat grid.

What's the difference between Layout and Full decorated?

Layout mode produces only gameplay-relevant geometry, so it stays readable and cheap on objects. Full decorated additionally generates block design, ground/background styling, pulses, move triggers and camera work — still using stock objects only.

Will it break when GD 2.3 comes out?

The mod is compiled against Geode's version-independent interface and doesn't hardcode game addresses. When a new game build ships, it typically needs a Geode update rather than a mod rewrite — and new object sets get added as they're documented.

Can I edit what it generates?

Yes — that's the point. Everything lands as normal editor objects you can select, move, delete or restyle. Each generation pass is a single undo entry, so Ctrl+Z removes a whole attempt cleanly.

Does it need an internet connection?

No. Generation and song analysis run locally on your machine. Nothing about your level or your music is uploaded anywhere.
