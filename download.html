Requires

Geometry Dash 2.2081 on Geode v5.0.0+ (stable line: v5.11.2). GD 2.2091 needs the Geode 6 beta and the matching GENESIS beta build.

Installing

Download → open GD → Geode → Install from file. Or drop the file into geode/mods and restart the game.

Updating

Install the newer file over the old one — settings and keybinds carry over. Downgrading needs the older file reinstalled.
