GENESIS 1.1.0-beta.1

A prerelase for Geometry Dash 2.2091 on Geode 6.0.0-alpha. This page walks you through installing that loader, installing the beta, what to test, and where to send what you find.

GD 2.2091 LOADER Geode 6.0.0-alpha CHANNEL beta · unlisted iOS not available
Neither piece of this is stable. Geode 6.0.0-alpha is a developer-facing prerelease and its own release notes say things will break. GD 2.2091 with an alpha loader can corrupt saves or crash on boot. Test on a copy of your save, not your main level folder — the backup step is below and it is not optional.
Step 0

Back up before you touch anything

  1. In GD, open Options → Backup (or your platform's save sync) and save a fresh backup. Note where it went.
  2. Copy any level you care about into practice — the beta writes into whatever level you have open.
  3. If you use the same device for real play, finish this on a spare install or a second profile.

Who this is for

People who can read a log file, find a mods folder, and reinstall their game if it breaks.

Who this isn't for

If you just want a working mod today: stay on v1.0.0 stable with GD 2.2081 and Geode v5.x.

iOS

There is no 2.2091 test build. The iOS loader is experimental and targets 2.2081 — skip this beta on iOS entirely.

Step 1

Install Geode 6.0.0-alpha on GD 2.2091

Geode 6 is the only loader line that supports GD 2.2091 — stable Geode 5.x is built for 2.2081 and will not load there. Alpha builds are published as pre-releases on the Geode repo, so they don't appear on the normal install page.

Open github.com/geode-sdk/geode/releases and pick the newest v6.0.0-alpha.x pre-release. Newer alphas fix 2.209 crashes, so don't pin an old one. If Geode's install page says the loader is currently broken for your game build, wait for the next alpha instead of forcing it.
  1. Quit Geometry Dash completely (check the tray / task manager — the loader can't replace files while it runs).
  2. Download geode-installer-v6.0.0-alpha.x-win.exe from the alpha release's assets.
  3. Run it and point it at your GD folder — Steam default: C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash
  4. Launch GD. The main menu should show the Geode button, and Geode → Settings should report 6.0.0-alpha.x.
  5. Your existing mods are not carried over — 5.x mods won't load on a 6.x loader. Expect an empty mods list.
Mods C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash\geode\mods
Logs C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash\geode\logs\Geode.log

If it won't boot: hold Shift from before launch until the game finishes loading — that's Geode's Safe Mode and it loads no mods at all.

  1. Quit Geometry Dash.
  2. Download geode-installer-v6.0.0-alpha.x-mac.pkg from the alpha release.
  3. Run the installer. If macOS blocks it: System Settings → Privacy & Security → Open Anyway.
  4. Launch GD through Steam and confirm the Geode version reads 6.0.0-alpha.x.
  5. 5.x mods don't carry over — the list will be empty until you install 6.x builds.
Mods ~/Library/Application Support/Steam/steamapps/common/Geometry Dash/Geometry Dash.app/Contents/geode/mods
Logs ~/Library/Application Support/Steam/steamapps/common/Geometry Dash/Geometry Dash.app/Contents/geode/logs/Geode.log

In Finder press Shift+Cmd+G and paste the path to jump straight there. Safe Mode is the same: hold Shift while launching.

Apple Silicon: the beta ships universal (arm64 + x86_64), so no Rosetta tricks are needed.

  1. Uninstall the old Geode launcher if you have one, then install the current Geode Android launcher APK from geode-sdk/android-launcher.
  2. In the launcher, install Geode for your GD 2.2091 install and pick the 6.0.0-alpha line when offered.
  3. Launch through the launcher. Geode → Settings should read 6.0.0-alpha.x.
  4. Grab the arm64-v8a beta build unless your device is genuinely old (then armeabi-v7a).
Mods /storage/emulated/0/Android/media/com.geode.launcher/game/geode/mods
Logs /storage/emulated/0/Android/media/com.geode.launcher/game/geode/logs/Geode.log

Safe Mode: press and hold the launcher's Launch button.

There is no Geode 6 / GD 2.2091 build for iOS, and no iOS beta of GENESIS. Nothing to install here.

If you're on iOS, stay on the stable line: GD 2.2081 + Geode v5.x + GENESIS v1.0.0, installed through the Geode iOS launcher. The mod itself is marked experimental on iOS even there.

Step 2

Install the beta .geode

File name genesis-1.1.0-beta.1-<platform>.geode
  1. Get the file from the beta card: download.html?channel=beta.
  2. Install from file: Geode → Mods → Install from file → pick the .geode.
  3. Or copy it into geode/mods using the path for your platform above, then restart GD.
  4. Verify it under Geode → Installed: it should read 1.1.0-beta.1 with no version warning.
Keep the filename exactly as downloaded. Renamed .geode files are refused by the loader — this bites hardest on iOS, where the file also has to be re-signed on install.

Release assets are attached to the v1.1.0-beta.1 pre-release on GitHub. If the download button sends you to the releases page instead of a file, the assets aren't uploaded yet — ping the thread.

Known issues — don't report these

  • Android decoration is the least-tested path. Gaps and missing visuals there are expected; a crash is not.
  • No iOS build for 2.2091. That's a loader limitation, not a mod bug.
  • Older mods failing to load on the 6.0.0-alpha loader — that's the alpha, not GENESIS.
  • GD 2.2091 itself is new; unrelated crashes on the alpha loader belong in Geode's issue tracker.
Step 4

Where to send what you find

Open an issue on GitHub with the beta template

One issue per problem. Use the Beta bug report template so the fields line up — it asks for everything below.

PLATFORM — Windows / macOS / Android + OS version GAME — GD build (2.2091) and where you got it LOADER — exact Geode alpha build, e.g. 6.0.0-alpha.2 MOD — GENESIS 1.1.0-beta.1 SEED — the seed shown in the panel (makes it reproducible) PROMPT — the exact text you used SETTINGS — version selector, gadget toggles, mode, difficulty LOGS — Geode.log, plus the crashlog if it crashed
Open a beta issue

Attach the log file directly rather than pasting the last line — the useful part is usually 30 lines above the failure. If a level triggers it, attach the level file too, or tell me the seed and prompt so it can be reproduced.

Please don't report alpha-loader bugs to the Geode team as GENESIS bugs, and don't post this page or the beta link publicly — it's unlisted on purpose.

Rolling back

  1. Uninstall GENESIS beta from Geode → Installed.
  2. Reinstall the stable loader for your game build (Geode v5.x for 2.2081, or whichever build you were on).
  3. Reinstall GENESIS v1.0.0 stable.
  4. Restore the save backup you made in step 0 if anything looks off.
